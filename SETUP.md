## Part 1: Backend Setup

### Step 1: Navigate to Project Root

```cmd
cd c:\Users\shart\Desktop\public-grievance-app
```

### Step 2: Clean and Build Backend

```cmd
mvn clean package -DskipTests
```

This will:
- Clean previous builds
- Compile all Java source files
- Run dependency checks
- Create JAR file in `target/` directory

### Step 3: Start Spring Boot Application

```cmd
mvn spring-boot:run
```

**Expected Console Output:**
```
[INFO] H2 console available at '/h2-console'
[INFO] Started PublicGrievanceAppApplication in 3.456 seconds
[INFO] Application startup complete - listening on port 8000
```

### Step 4: Verify Backend is Running

Open a new terminal and run:

```cmd
curl -i http://localhost:8000/api/users
```

Expected Response:
```
HTTP/1.1 401 Unauthorized
```

This confirms the endpoint exists. 401 means authentication is required (expected).

## Part 5: API Endpoints Reference

All endpoints use HTTP Basic Authentication.

### Users API
```
GET    /api/users           - Get all users
POST   /api/users           - Create new user
GET    /api/users/{id}      - Get user by ID
PUT    /api/users/{id}      - Update user
DELETE /api/users/{id}      - Delete user
```

### Grievances API
```
GET    /api/grievances           - Get all grievances
POST   /api/grievances           - Create new grievance
GET    /api/grievances/{id}      - Get grievance by ID
PUT    /api/grievances/{id}      - Update grievance
DELETE /api/grievances/{id}      - Delete grievance
```

### Departments API
```
GET    /api/departments     - Get all departments
POST   /api/departments     - Create new department
GET    /api/departments/{id} - Get department by ID
```

### Attachments API
```
GET    /api/attachments     - Get all attachments
POST   /api/attachments     - Upload attachment
DELETE /api/attachments/{id} - Delete attachment
```

### Updates API
```
GET    /api/updates         - Get all grievance updates
POST   /api/updates         - Create update
DELETE /api/updates/{id}     - Delete update
```

## Part 6: Troubleshooting

### Issue: Port 8000 Already in Use

**Solution:**
```cmd
# Find process using port 8000
netstat -ano | findstr :8000

# Kill the process (replace PID with actual process ID)
taskkill /PID <PID> /F
```

Then restart with:
```cmd
mvn spring-boot:run
```

### Issue: Frontend Can't Connect to Backend

**Check:**
1. Backend is running on port 8000: `http://localhost:8000/api/users`
2. Credentials are correct in `frontend/src/services/api.js`
3. Browser console for CORS errors (should not appear - using Basic Auth)
4. Firewall not blocking localhost connections

**Solution:**
```cmd
# Restart both services
# Terminal 1: Backend
mvn spring-boot:run

# Terminal 2: Frontend
cd frontend
npm run dev
```

### Issue: 401 Unauthorized Errors

**Cause:** Wrong credentials in `frontend/src/services/api.js`

**Solution:**
1. Check backend startup logs for generated password
2. Update credentials in api.js
3. Refresh browser page

### Issue: npm install Fails

**Solution:**
```cmd
# Clear npm cache
npm cache clean --force

# Delete node_modules and package-lock.json
rm -r node_modules package-lock.json

# Retry install
npm install
```

### Issue: Maven Build Fails

**Solution:**
```cmd
# Update Maven
mvn -v  # Check version

# Clean rebuild
mvn clean install -DskipTests

# If still fails, check Java version
java -version  # Should be 21+
```
